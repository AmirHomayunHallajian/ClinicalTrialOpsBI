# Portfolio Positioning
Use this project to show end-to-end BI thinking from data generation to executive storytelling.

## CV Bullets
**ClinicalTrialOpsBI — Power BI Dashboard for Clinical Trial Operations**
- Built a synthetic clinical-trial operations dataset and designed a Power BI dashboard to monitor recruitment, site activation, query resolution, missing documents, cycle time, and digital adoption KPIs.
- Created a star-schema data model, documented DAX measures, and designed executive and operational dashboard pages for pharma/CRO-style decision-making.
- Demonstrated BI storytelling, KPI design, healthcare analytics domain knowledge, and reproducible mock data generation using Python.

## Interview Pitch
"I built this project to show that I can translate operational clinical-trial processes into a business-facing BI dashboard. The dashboard tracks recruitment, site activation, query resolution, missing documents, cycle times, and adoption metrics. I generated a synthetic dataset in Python, modeled it as a star schema, documented DAX measures, and designed dashboard pages for different stakeholders such as clinical operations managers, data managers, and site monitors."
