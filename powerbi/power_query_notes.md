# Power Query Notes
- Set date fields to Date type.
- Set booleans to True/False type.
- Set keys (`study_id`, `site_id`, `user_id`) as Text.
- Disable Auto Date/Time in Power BI options if using `dim_date`.
- Validate relationship cardinality as one-to-many.
- Avoid bidirectional filters unless required.
- Format percentage KPIs and day-based metrics clearly.
