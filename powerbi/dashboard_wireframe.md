# Dashboard Wireframes
## 1) Executive Overview
Purpose: leadership snapshot of operations.
Slicers: study, country, month.
KPIs: randomized, attainment %, active sites, activation rate, avg query days, SLA %, missing critical docs, avg adoption.
Visuals: KPI cards, enrollment trend, activation status bar, query backlog by priority, missing docs by country, adoption by role.

## 2) Recruitment Performance
KPIs: screened, randomized, screen failure rate, attainment %, velocity, below-target sites.
Visuals: actual vs target trend, country comparison, site ranking, funnel, underperforming matrix.

## 3) Site Activation and Start-Up
KPIs: planned/activated/delayed, median cycles.
Visuals: status stacked bar, delay by country, cycle chart, timeline, top delayed sites.

## 4) Data Quality and Query Management
KPIs: open/overdue queries, avg days, SLA %, queries per randomized participant.
Visuals: trend, category split, aging buckets, SLA met/not, site backlog table.

## 5) Document Completeness / TMF Readiness
KPIs: required/received/approved/missing/critical missing/completion %.
Visuals: status stacks, missing by doc type, critical missing by site, completion by country, overdue table.

## 6) Adoption and Operational Behavior
KPIs: active users, adoption score, training %, days since login, EDC/eTMF usage.
Visuals: adoption trend, by role, training by country, logins vs forms scatter, low-adoption site table.
